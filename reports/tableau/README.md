# Tableau deliverables

This folder is a Tableau-ready source package governed by the shared KPI dictionary.

- `calculated_fields.txt`: exact calculated fields to create.
- `dashboard_specification.md`: worksheet, dashboard, filter, action, and formatting contract.
- `tableau_explorer_preview.png`: target layout for the focused analytical dashboard.
- `tableau_validation_preview.png`: target validation layout.

Connect Tableau Desktop/Public to `data/processed/telco_customer_churn_clean.csv`, then follow `docs/tableau_model_and_build_guide.md`. A `.twb/.twbx` is not included because the installed Tableau application could not be controlled and validated in this session; static assets are not mislabeled as an interactive workbook.
